# API Contract: Authentication Endpoints

**Feature**: 005-auth-system | **Service**: Frontend (Better Auth) | **Base URL**: `http://localhost:3000`

> These endpoints are handled by Better Auth's catch-all route handler at `/api/auth/[...all]/route.ts`.
> The frontend code does not implement these — they are auto-generated by Better Auth.
> Documented here for reference and backend integration.

---

## POST /api/auth/sign-up/email

**Purpose**: Register a new user account (FR-001, FR-002, FR-003, FR-004)

**Request**:
```json
{
  "name": "string (required)",
  "email": "string (required, valid email)",
  "password": "string (required, min 8 chars)"
}
```

**Response 200** (success):
```json
{
  "user": {
    "id": "uuid-string",
    "name": "John Doe",
    "email": "john@example.com",
    "emailVerified": false,
    "image": null,
    "createdAt": "2026-02-08T12:00:00.000Z",
    "updatedAt": "2026-02-08T12:00:00.000Z"
  },
  "session": {
    "id": "session-id",
    "token": "session-token",
    "userId": "uuid-string",
    "expiresAt": "2026-02-08T13:00:00.000Z"
  }
}
```

**Response 422** (validation error):
```json
{
  "message": "Password must be at least 8 characters"
}
```

**Response 409** (duplicate email):
```json
{
  "message": "User already exists"
}
```

**Notes**: Sets session cookies automatically. User is auto-signed-in after registration.

## POST /api/auth/sign-in/email

**Purpose**: Authenticate user and create session (FR-005, FR-006)

**Request**:
```json
{
  "email": "string (required)",
  "password": "string (required)",
  "rememberMe": "boolean (optional, default true)"
}
```

**Response 200** (success):
```json
{
  "user": {
    "id": "uuid-string",
    "name": "John Doe",
    "email": "john@example.com",
    "emailVerified": false,
    "image": null,
    "createdAt": "2026-02-08T12:00:00.000Z",
    "updatedAt": "2026-02-08T12:00:00.000Z"
  },
  "session": {
    "id": "session-id",
    "token": "session-token",
    "userId": "uuid-string",
    "expiresAt": "2026-02-08T13:00:00.000Z"
  }
}
```

**Response 401** (invalid credentials):
```json
{
  "message": "Invalid email or password"
}
```

**Notes**: Sets session cookies. The `set-auth-jwt` header may also be returned.

## POST /api/auth/sign-out

**Purpose**: End user session and clear cookies (FR-013)

**Request**: Empty body. Session identified by cookies.

**Response 200** (success):
```json
{
  "success": true
}
```

**Notes**: Clears session cookies. Deletes session row from database.

## GET /api/auth/token

**Purpose**: Obtain a JWT bearer token for external API calls (FR-006, FR-007)

**Request**: No body. Session identified by cookies.

**Response 200**:
```json
{
  "token": "eyJhbGciOiJFZERTQSIsInR5cCI6IkpXVCIsImtpZCI6Imt..."
}
```

**Response 401** (no session):
```json
{
  "message": "Unauthorized"
}
```

**JWT Payload** (decoded):
```json
{
  "sub": "uuid-string",
  "id": "uuid-string",
  "email": "john@example.com",
  "name": "John Doe",
  "iss": "http://localhost:3000",
  "aud": "http://localhost:3000",
  "exp": 1707400800,
  "iat": 1707397200
}
```

**Notes**: Token is signed with EdDSA (Ed25519). The `kid` header identifies the signing key. This is the token sent to the FastAPI backend as `Authorization: Bearer <token>`.

## GET /api/auth/jwks

**Purpose**: Expose public keys for JWT verification (used by backend)

**Request**: No authentication required.

**Response 200**:
```json
{
  "keys": [
    {
      "kty": "OKP",
      "crv": "Ed25519",
      "x": "base64url-encoded-public-key",
      "kid": "key-id-string"
    }
  ]
}
```

**Notes**: Standard JWKS format per RFC 7517. The backend's `PyJWKClient` fetches this endpoint to verify JWT signatures. Multiple keys may appear during rotation grace periods.
